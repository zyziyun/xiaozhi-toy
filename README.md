# Xiaozhi AI Toy

A custom AI-powered companion toy built with ESP32-S3 and the Xiaozhi ecosystem.

Self-study project following MIT MAS.863 "How to Make (Almost) Anything".

## Features

- Voice conversation (wake word + STT + LLM + TTS)
- Animated eye displays (ST7735 TFT)
- Servo-driven head movement
- LED emotion indicators
- Web control console
- Self-hosted AI backend (Whisper + Claude + TTS)

## Hardware

- ESP32-S3 N16 (Xiaozhi)
- INMP441 MEMS microphone
- NS4168 audio amplifier + speaker
- 0.85" ST7735 TFT × 2 (eyes)
- SG90 servo × 2 (head pan/tilt)
- TP4056 LiPo charger + 3.7V 1200mAh battery
- Custom PCB (JLCPCB)
- 3D printed enclosure
